# .agents

Memoria operativa para que Codex trabaje este repo de forma consistente.

Archivos principales:

- `AGENTS.md`: reglas generales del repo, arquitectura, Git, validaciones y comunicación.
- `skills/implementar-historia/SKILL.md`: flujo para implementar una historia de usuario.
- `skills/revisar-historia/SKILL.md`: flujo para verificar si una historia cumple checklist.
- `skills/cerrar-pr/SKILL.md`: flujo para commit, push, PR y merge a `develop`.
- `skills/seguridad/SKILL.md`: revisión de seguridad enfocada en este proyecto.

Uso sugerido en un chat nuevo:

```text
Lee .agents/AGENTS.md y usa la skill .agents/skills/implementar-historia/SKILL.md para continuar con US-XXX.
```
